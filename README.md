# B2B Serviços — Site institucional

HTML + CSS + JS (Three.js + GSAP). **Sem `npm install`.** Requer internet (fontes, GSAP e imagens do site oficial).

## Rodar no CMD
Node.js:  `node server.js`  → http://localhost:3000
Python:   `python serve.py` → http://localhost:8000
Windows:  duplo clique em `iniciar.bat`

## Personalizar
- **WhatsApp:** edite `public/config.js` (número e mensagem padrão).
- **Fotos:** troque os `src` das imagens em `public/index.html` (ideal: fotos reais da equipe).
- **Jogo:** `public/game.js` (B2B Runner, no final da página).
- **Depoimentos:** há um comentário no HTML (seção "Quem somos") indicando onde adicionar.
